# 🛒 Clothing E-Commerce Store (Laravel 12 & Filament v3)

متجر إلكتروني متكامل لبيع الملابس مبني باستخدام إطار العمل **Laravel 12** ولوحة التحكم الاحترافية **Filament PHP v3** مع دعم كامل لبنية **HMVC (Modules)** لإدارة الأكواد بكفاءة ونظافة عالية.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

* **Backend:** Laravel 12 & PHP 8.2+
* **Admin Panel:** Filament PHP v3 (مع دعم حزم تبديل اللغات وتخصيص الـ Widgets)
* **Frontend Components:** Livewire v3 & Tailwind CSS
* **Architecture:** HMVC (Hierarchical Model-View-Controller) باستخدام حزمة `nwidart/laravel-modules`
* **Database:** MySQL

---

## 💎 المميزات الرئيسية (Key Features)

* **بنية موديولات منفصلة (HMVC):** تقسيم المشروع لموديولات مستقلة مثل موديول الكتالوج (`Catalog Module`) لسهولة التطوير والصيانة.
* **لوحة تحكم ذكية:** إدارة كاملة للمنتجات، الأقسام (Categories)، والمخزن عبر Filament.
* **نظام لغات مرن:** تبديل كامل وسلس بين اللغتين العربية والإنجليزية في لوحة التحكم (Filament Language Switch).
* **فلترة ديناميكية:** فلترة وتصفية المنتجات في الفرونت إند باستخدام Livewire بدون ريفريش للصفحة وبأداء فائق السرعة بناءً على القسم المختار.
